# spec — วางแนวทาง/ข้อกำหนดของระบบไว้ที่นี่ (คนเตรียม)
ไฟล์ที่ควรมี (Markdown หรือ PDF ที่แปลงเป็นข้อความแล้ว):
- `overview.md` เป้าหมาย ผู้ใช้ ขอบเขตระยะ 1
- `process.md` ขั้นตอนงานจริงตั้งแต่ต้นจนจบ ใครทำอะไร เอกสารอะไร
- `rules.md` เงื่อนไขธุรกิจ (เกณฑ์อนุมัติ ระยะประกัน วงเงิน ฯลฯ)
- `reports.md` รายงาน/ตัวชี้วัดที่ผู้บริหารต้องการ
- `forms/` ตัวอย่างแบบฟอร์มปัจจุบัน **ลบข้อมูลลูกค้าจริงออกก่อน** (PDPA)
ห้ามใส่: ข้อมูลลูกค้าจริง, รูปงานจริงที่เห็นหน้า/ทะเบียนรถ, รหัสผ่าน
