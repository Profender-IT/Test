# ADR 0002 — เรื่องที่ต้องตัดสินก่อนออกแบบละเอียด (เปิดอยู่)
- สถานะ: รอตัดสิน · งาน ROOM-2 เตรียมตัวเลือกให้เจ้าของโปรเจค
| # | คำถาม | ตัวเลือก | ผลต่อระบบ |
|---|---|---|---|
| 1 | ผู้ใช้ภายนอก (ตัวแทน/ศูนย์บริการ/ลูกค้า) ใช้ระบบไหม | ก. ภายในเท่านั้น · ข. ภายนอกผ่านอินเทอร์เน็ต | ข. ต้องมี server ใน DMZ หรือแยกออกจาก .176/.177, MFA, rate limit, WAF |
| 2 | ระบบ auth (ต้องเป็น OIDC ตาม ADR 0003) | Keycloak ในโรงงาน (เชื่อม AD) · Microsoft Entra · Cognito | กระทบ SSO และการจัดการผู้ใช้ |
| 3 | ไฟล์แนบ (รูป/วิดีโอ) | ตัดสินแล้วใน ADR 0003: S3 API (MinIO on-prem → S3) · ที่ต้องตัดสินคือขนาด/ระยะเก็บ | ขนาดดิสก์, backup |
| 4 | ระยะเก็บข้อมูลส่วนบุคคล/ไฟล์ | ตามกฎหมาย/นโยบายบริษัท | งานลบอัตโนมัติ, audit |
| 5 | เชื่อมระบบอื่น (ERP, ทะเบียนสินค้า, SCADA/QC) | API · import ไฟล์ · ไม่เชื่อม | งาน integration, สิทธิ์ DB |
