# ADR 0002 — เรื่องที่ต้องตัดสินก่อนออกแบบละเอียด (เปิดอยู่)
- สถานะ: รอตัดสิน · งาน ROOM-2 เตรียมตัวเลือกให้เจ้าของโปรเจค
| # | คำถาม | ตัวเลือก | ผลต่อระบบ |
|---|---|---|---|
| 1 | Supabase region + DPA (PDPA) | ก. Singapore (ap-southeast-1) · ข. self-host Supabase ในองค์กร | ข้อมูลพนักงานออกนอกประเทศ → ต้องผ่าน DPO/ฝ่ายกฎหมายก่อน production |
| 2 | การล็อกอิน | ก. อีเมล+รหัสผ่าน (Supabase Auth) · ข. Microsoft Entra (Azure AD) ผ่าน Supabase SSO/OAuth · ค. Magic link | ข. ใช้บัญชีบริษัท ปิดผู้ใช้ที่ลาออกได้ทันที |
| 3 | ใครจองได้/อนุมัติ | ก. ทุกคนจองได้ทันที · ข. บางห้องต้องให้ผู้ดูแลห้องอนุมัติ | state machine ของการจอง, บทบาท, แจ้งเตือน |
| 4 | กติกาการจอง | ระยะจองล่วงหน้าสูงสุด, ความยาวสูงสุด, จองซ้ำทุกสัปดาห์, เช็กอิน/ปล่อยห้องเมื่อไม่มา | constraint ใน DB, งานเบื้องหลัง (pg_cron/Edge Function) |
| 5 | แจ้งเตือน | ก. ในแอป · ข. push (FCM) · ค. อีเมล/ปฏิทิน Outlook | FCM ต้องเพิ่ม google-services + secret ใน CI |
| 6 | เชื่อมปฏิทินบริษัท | ไม่เชื่อม · export .ics · sync Microsoft 365 | Edge Function + สิทธิ์ Graph API |
